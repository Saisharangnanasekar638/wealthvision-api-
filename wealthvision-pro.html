☁️ Deploy to Render (Free Hosting)

1. Push app.py + requirements.txt to GitHub
2. Go to render.com → New Web Service
3. Connect GitHub repo → Build: pip install -r requirements.txt
4. Start: gunicorn app:app
5. Copy your Render URL (e.g. https://wealthvision-api.onrender.com) and paste above
